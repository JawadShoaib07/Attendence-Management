# Publish CampusDesk to GitHub

GitHub profile: https://github.com/JawadShoaib07

Suggested repository name: `CampusDesk-Student-Management-System`
Suggested URL (only after you create it): https://github.com/JawadShoaib07/CampusDesk-Student-Management-System

## Steps
1. Sign in to GitHub and open https://github.com/new
2. Repository name: `CampusDesk-Student-Management-System`. Choose Public if your instructor needs to view it. Do not initialize it with a README because this project already has one.
3. Open a terminal inside this project folder and run:

```bash
git init
git add .
git commit -m "Build CampusDesk student management system"
git branch -M main
git remote add origin https://github.com/JawadShoaib07/CampusDesk-Student-Management-System.git
git push -u origin main
```

4. Open the repository in your browser and confirm the files are visible. Only then use the repository URL in your assignment as a live repository link.

The GitHub profile URL and a repository URL are different. This guide does not mean that the repository has already been created or uploaded.
